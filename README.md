# IITM MLP Project - T22025 Term

This repository contains my Machine Learning Project (MLP) for the Diploma Level of BS in Data Science and Applications at IIT Madras.

## Project Goal

The goal of this project is to predict customer purchase value based on their multi-session digital behavior using machine learning models. The dataset includes anonymized user interactions such as browser types, traffic sources, device details, and geographical indicators.

## How This Project Works

- I perform exploratory data analysis (EDA) to understand the dataset and extract meaningful insights.
- I build and compare multiple machine learning models to find the best predictor.
- Hyperparameter tuning is done using grid search and randomized search techniques.
- The final model is used to generate predictions on the test data.
- Submissions are made through the Kaggle competition platform associated with this project.

## Key Files

- `gridSearchAllOut.py` - Script for hyperparameter tuning using grid search.
- `randomisedSearch.py` - Script for hyperparameter tuning using randomized search.
- `train_data.csv` and `test_data.csv` - Dataset files.
- `sample_submission.csv` - Sample format for submission.

This project is part of the coursework and reflects my learning and application of machine learning techniques.
