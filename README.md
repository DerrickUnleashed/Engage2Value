# IITM MLP Project - May 2025 Term

This repository contains my Machine Learning Project (MLP) for the Diploma Level of BS in Data Science and Applications at IIT Madras.

## Project Goal

The goal of this project is to predict customer purchase value based on their multi-session digital behaviour using machine learning models. The dataset includes anonymised user interactions such as browser types, traffic sources, device details, and geographical indicators.

## How This Project Works

- Perform exploratory data analysis (EDA) to gain a deeper understanding of the dataset and extract meaningful insights.
Build and compare multiple machine learning models to identify the most effective predictor.
- Hyperparameter tuning is done using grid search and randomised search techniques.
- The final model is used to generate predictions on the test data.
- Submissions are made through the Kaggle competition platform associated with this project.

## Key Files

- `gridSearchAllOut.py` - Script for hyperparameter tuning using grid search.
- `randomisedSearch.py` - Script for hyperparameter tuning using randomised search.
- `train_data.csv` and `test_data.csv` - Dataset files.
- `sample_submission.csv` - Sample format for submission.

This project is part of the coursework and reflects my learning and application of machine learning techniques.
